
# Smart Dukaan

Smart Dukaan is a web application built using Angular
and modern frontend technologies.

## Technology Stack

- Angular
- TypeScript
- JavaScript
- HTML5
- CSS3

## Project Structure

- src/ - Application source code
- public/ - Static assets
- angular.json - Angular configuration
- package.json - Project dependencies

## Features

- Responsive User Interface
- Modern Web Application
- Component-Based Architecture
- Angular Routing (if implemented)
- Reusable Components

## Installation

Clone the repository:

git clone https://github.com/priyankakoshta2001/Smart-Dukaan.git

Navigate to project:

cd Smart-Dukaan

Install dependencies:

npm install

Run the application:

ng serve
